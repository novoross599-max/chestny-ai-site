# Ошибки

## Загрузка шаблона Astro

- Ошибка: `create-astro` не смог скачать шаблон minimal с GitHub из-за сетевого тайм-аута.
- Причина: соединение с `codeload.github.com` завершилось по тайм-ауту.
- Исправление: минимальный каркас Astro создан вручную по структуре skill; зависимости успешно установлены через npm, сборка проверена.

## Сборка в песочнице

- Ошибка: Astro/esbuild не мог читать часть каталогов и создавать файл телеметрии за пределами проекта.
- Причина: ограничения файловой песочницы.
- Исправление: телеметрия отключена переменной `ASTRO_TELEMETRY_DISABLED=1`, проверочная сборка выполнена с разрешением на локальный доступ; `npm run build` завершён успешно.

## Автоматическая визуальная проверка localhost

- Ошибка: встроенный браузер отклонил обновление страницы `http://127.0.0.1:4321/` по своей URL-политике.
- Причина: ограничение browser security policy для локального адреса в текущей сессии, не ошибка сайта.
- Проверка: dev-сервер подтверждён ответом `200 OK`; собранный HTML, якоря, медиазапросы, disabled-состояния форм и коэффициенты контраста проверены отдельно. Для окончательной визуальной оценки страницу можно открыть вручную по локальному адресу.

## Git в песочнице

- Ошибка: после `git init` операции записи в `.git` завершались `Permission denied`, а проверка репозитория сообщала `dubious ownership`.
- Причина: служебный пользователь песочницы отличается от владельца рабочей папки Windows.
- Исправление: чтение выполняется с точечным `safe.directory`, а необходимые операции записи Git запускаются в пользовательском контексте с разрешением; глобальная конфигурация Git не изменяется.
