# Постоянные требования пользователя

- Перед началом каждой новой задачи читать все файлы из `.agent_memory` и учитывать их содержимое.
- После выполнения существенной задачи обновлять соответствующие файлы памяти.
- Поддерживать в `project_state.md` актуальные сведения о выполненной работе и следующем шаге.
- Записывать в `decisions.md` важные решения и причины их принятия.
- Записывать в `bugs.md` обнаруженные ошибки, их причины и способы исправления.
- Хранить в `user_rules.md` постоянные требования и предпочтения пользователя.
